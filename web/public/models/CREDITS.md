## Blender-built HD models (`hd/`)

Every `hd/*.glb` is generated by the scripts in `tools/blender/` (`build_burger.py` for the burgers, `build_dish.py` for all other dishes) and is part of this project. Sources used inside them:

- **Hamburger Buns** scan (https://polyhaven.com/a/hamburger_buns, CC0) — cut in half and colour-graded to brioche for the Classic Cheeseburger, Double Bacon Burger and Kids Mini Burger.
- **Wooden Cutting Board** scan (https://polyhaven.com/a/wooden_cutting_board, CC0) — the board under the shawarma wraps and the shashlik.
- Everything else (serving ware with the Uzbek paxta pattern, food, sauces, garnishes) is modelled procedurally in Blender; textures are painted in code or baked from procedural materials.

Each ingredient is a separate node (named with the meal's ingredient id) so the viewer can pull it apart; the plate / glass / board is one static node.
